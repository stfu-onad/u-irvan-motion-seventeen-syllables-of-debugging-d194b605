A Python program that writes one haiku about debugging — three lines in the 5-7-5 syllable shape, at most 200 characters — to `/output/entry.txt`, for make.fun's "Seventeen Syllables of Debugging" bounty. The haiku: a breakpoint holds its breath, the log line swears nothing changed, and the last line turns it — it was me, always.

## Run it

```sh
python3 main.py
```
